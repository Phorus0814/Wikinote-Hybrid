WNH 상세

주요 추천 대상 (Target Audience)
기획자 및 시스템 설계자
  -복잡한 사양 정의서, 기능 요건 설명서, 테이블 정의서 등을 구조화된 상하 계층 트리로 명확히 관리하고 기능 간의 종속 관계를 역링크 참조로 분석하여 설계 누락을 방지하고자 하는 경우.
시나리오 작가 및 세계관 설정가
  -방대한 캐릭터 설정, 인물 관계도, 시놉시스, 단체 및 배경 설정을 위키 방식([[제목]])으로 촘촘히 엮어 설정 간의 모순을 예방하고, 에디터 내 빠른 내비게이션을 통해 저작 효율을 높이고자 하는 경우.

1. 데이터 저장 및 관리 아키텍처 (Storage & State)

이 애플리케이션은 로컬 웹 브라우저 환경에서 모든 데이터를 안전하게 저장하고 무중단 작동을 보장하기 위해 하이브리드 스토리지 설계를 취하고
있습니다.

  - IndexedDB 통합 데이터베이스 엔진:
      - com.wikinote.hybrid라는 이름의 데이터베이스와 workspace_data 객체 저장소(Object Store)를
        활용하여 대용량 기획 데이터와 텍스트를 안정적으로 기록합니다.
      - 비동기 트랜잭션 방식으로 상태가 변경될 때마다 appState 전체가 IndexedDB에 안전하게 동기화됩니다
        (saveStateToCache 함수).
  - LocalStorage 하이브리드 폴백:
      - IndexedDB 초기화 실패 또는 예외 상황 발생 시, 과거 버전 호환성을 위해 wnh_shortcut_v2 키를 통한 로컬
        스토리지 데이터 복구 기 메커니즘을 내장하고 있습니다.
  - 초기 상태 모델 수립:
      - 최초 실행 시 데이터가 전혀 존재하지 않으면 "doc-root"(최상위 루트) 노드를 포함하는 기본 프로젝트를 자동 구성하여
        무오류 구동 환경을 보장합니다.

2. 프로젝트 런처 대시보드 (Launcher Dashboard)

사용자가 워크스페이스에 진입하기 전, 여러 개의 독립적인 기획 프로젝트를 관리하고 데이터를 입출력할 수 있는 게이트웨이 화면입니다.

  - 프로젝트 수명 주기 관리:
      - 생성: 커스텀 프롬프트를 통해 새 프로젝트 이름을 입력받고 고유 무작위 ID(예: proj-xxxxxxxxx)를 생성하여 신규
        프로젝트 인스턴스를 발급합니다.
      - 선택 및 검사: 목록에서 특정 프로젝트를 클릭하면 상세 패널(인스펙터)에 문서 개수, 구동 모드 정보 등이 표시됩니다.
      - 삭제: 프로젝트 삭제 시 사용자 확인을 거친 후 하위의 모든 문서를 영구 제거합니다.
  - 프로젝트 대형 가져오기(Import) 시스템:
      - .zip, .7z 압축 아카이브 또는 단일 통합 .txt 형식의 기획서 파일을 감지하여 파싱하는 지능형 모듈입니다.
      - ZIP/7z 파싱: JSZip 라이브러리를 통해 압축 해제 후 1.1. 제목.md와 같은 파일명 규칙을 정규식으로 분석하여 문서의
        트리 깊이(Depth)와 순서(Index)를 자동으로 역컴파일 및 복원합니다.
      - 통합본 TXT 파싱: 단일 텍스트 내에서 특정 규격(예: 1.1. 제목 \n ----------)으로 구분된 헤더 영역을 추출하여
        일치하는 다수의 문서 노드로 계층을 재분할하고 자동으로 트리 구조로 생성해 줍니다.
  - 프로젝트 다각화 내보내기(Export) 시스템:
      - ZIP / 7z 압축 내보내기: JSZip 엔진으로 개별 계층에 맞춰 가상 경로 파일명(1.2. 개요.md 등)을 매핑하여
        압축하고, 전체 문서를 한눈에 보는 통합본.txt를 포함하여 다운로드 처리를 실행합니다.
      - 폴더 다이렉트 내보내기 (File System Access API): 브라우저의 최신 기술인 showDirectoryPicker를
        호출하여 OS 로컬 폴더에 실제 마크다운 파일과 통합본 텍스트를 즉시 생성 및 갱신해 줍니다.
      - 통합본 단일 파일 다운로드: 트리 구조 순서대로 모든 문서 본문을 병합한 단일 기획 텍스트 파일을 추출해 줍니다.

3. 워크스페이스 계층형 트리뷰 (Workspace Treeview)

좌측 사이드바는 전체 기획서의 목차를 다루는 계층 구조 트리 엔진으로, 파일 탐색기와 유사한 수준의 UX를 제공합니다.

  - 동적 번호 스키마 생성 (rebuildIndexMaps):
      - 트리의 실제 저장 형태는 부모-자식 간의 참조 관계 구조(parentId 및 childIds 배열)입니다.
      - 화면에 표시될 때는 최상위 루트 노드인 "0"번을 기점으로, 모든 자식 노드들의 논리적 위치를 순회하며 1, 1.1, 1.1.2
        형태의 점 표기법(Dot Notation) 목차 번호를 계산하고 이를 UUID와 1:1로 매핑하는 캐시 구조를 갱신합니다.
  - 다중 확장/축소 상태 영속화:
      - 각 문서 노드의 개폐 상태가 expandedNodes 배열에 유지되므로, 다른 문서를 넘나들거나 새로고침을 하더라도 사이드바의
        확장 레이아웃 상태가 보존됩니다.
  - 동일 위상 다중 선택 (Multi-Select) 메커니즘:
      - 사용자가 Ctrl + 클릭 또는 Shift + 클릭을 수행할 경우, 계층 구조의 왜곡을 방지하기 위해 현재 동일한 부모를 공유하고
        있는 동일 레벨(위상)의 노드들만 다중 선택되도록 엄격히 통제합니다.
  - 실시간 충돌 방지 드래그 앤 드롭 (DND) 엔진:
      - 마우스 드래그 및 모바일 터치 이벤트를 동시 지원합니다.
      - 순환 구조 방지: 드래그가 감지되면 선택된 노드 및 하위 모든 자식 노드의 ID 목록을 차단 목록(Blacklist)으로
        등록하여, 상위 부모 노드가 자신의 하위 자식 노드 안으로 들어가 무한 루프가 발생하는 현상을 원천 차단합니다.
      - 정밀 위치 판정: 대상 노드의 상하 비율(Y좌표 기준 상위 25% 미만은 before로 이전 삽입, 하위 75% 초과는
        after로 이후 삽입, 그 외 영역은 inside로 하위 문서 삽입)을 실시간으로 추적하여 전용 인디케이터 라인과 동그라미
        표식 등 다양한 CSS 가이드를 입혀 줍니다.
  - 사이드바 전용 단순 우클릭 컨텍스트 메뉴:
      - 노드를 우클릭하면 해당 위치에 하위 문서 추가, 문서 삭제, 역링크 보기, 잘라내기, 복사, 붙여넣기 기능이 있는 커스텀 컨텍스트
        메뉴가 열립니다.
      - 루트 노드인 "0"번 노드에 대해서는 "삭제" 및 "잘라내기" 항목을 노출하지 않는 등 동적 제약 조건이 걸려 있습니다.
      - 클립보드 데이터 구조를 보관하는 clipboardNode 변수를 두어, 프로젝트가 동일할 때에 한해 트리 노드의 계층
        복제(Copy) 및 계층 이동(Cut) 처리가 붙여넣기를 통해 수행되도록 지원합니다.

4. 초정밀 대칭형 실시간 마크다운 에디터 Overlay (Symmetric WYSIWYG Editor)

텍스트 에디터는 마크다운 코드의 수정 편의성과 시각적인 실시간 하이라이팅을 동시에 제공하기 위해 **이중 레이어 설계(Double Layer
Design)**를 적용하고 있습니다.

  - 완전 투명 입력창과 렌더링 오버레이의 결합:
      - 글자색과 선택 영역 캐럿(Caret)을 제외하고 모든 글자가 완전히 투명 처리된 실제 입력용 <textarea>가 전면에
        배치되고, 그 후면에 하이라이트 처리가 완료된 <div> 요소가 배치됩니다.
      - 두 레이어의 너비, 높이, 패딩, 폰트, 자간, 단어 쪼갬 규칙(word-break), 폰트 렌더링 스무딩 등 모든 타이포그래피
        스타일을 완벽하게 0픽셀 단위로 대칭 정렬하여 글자의 일그러짐 현상 없이 완벽히 겹쳐 보이도록 설계되었습니다.
  - 3가지 고대비 실시간 토큰 파싱:
    1.  위키 링크 ([[링크]]):
          - 현재 활성화된 문서의 제목을 가리키면 주황색 점선 형태의 자기 참조(code-link-self)로 렌더링됩니다.
          - 프로젝트에 실존하는 다른 문서를 가리키면 파란색 밑줄 형태의 활성 링크(code-link-valid)로 처리됩니다.
          - 프로젝트에 없는 빈 경로를 가리키면 주황색 취소선 형태의 깨진 링크(code-link-broken)로 시각화됩니다.
    2.  33종 프리미엄 하이라이트 컬러 토큰:
          - 특정 약속 기호(예: $r빨간색텍스트$) 형식으로 입력하면 문장 중간에 하이라이트 컬러를 정밀 렌더링합니다.
          - 라벨 문자 $r 등은 투명하게 비활성화 처리하고 본문 영역에만 약속된 고유의 헥사코드 색상이 씌워집니다.
    3.  라인 기반 전체 컬러 변경 및 주석:
          - 줄 첫머리에 $r 등의 기호와 띄어쓰기를 입력하면 해당 줄 전체의 색상을 변경합니다.
          - 줄 시작 부분이나 띄어쓰기 뒤에 붙은 // 구문은 무채색 계열의 코드 주석 색상으로 변경됩니다.
  - 에디터 입력 편의 제어 기술:
      - Tab / Shift+Tab 제어: 브라우저 기본 포커스 이동을 차단하고 2칸의 들여쓰기 공간을 삽입하거나 기존 들여쓰기 공간을
        정확히 역산하여 삭제해 줍니다.
      - Enter 줄바꿈 인덴트 상속: 새 줄을 만들 때 바로 전 단계 줄에 작성된 공백이나 탭 크기를 역추적하여 자동으로 들여쓰기가
        이어진 채 입력이 시작되도록 유도합니다.
      - 스마트 백스페이스: 빈 들여쓰기 공간에서 백스페이스를 누르면 들여쓰기 규격 단위(2칸 공백 등)를 통째로 판단하여 한 번에 지워
        줍니다.
      - 콘텐트 반응형 오토 사이징 및 커서 유도 스크롤: 글 내용이 많아져 높이가 증가하면 가상 캔버스의 높이도 동반 상승시키고, 타이핑
        중인 줄의 캐럿 Y 위치를 분석해 스크롤 컨테이너 바깥으로 입력선이 이탈하지 않도록 감시하고 시야 내로 강제 유지합니다.

5. 위키 네트워킹 및 역링크(Backlink) 추적 시스템

문서들이 단방향 트리가 아닌 네트워크 형태의 웹(Web) 구조로 자라날 수 있도록 지능적인 링크 수집 및 리팩토링 모듈이 작동합니다.

  - 다방향 링크 식별 엔진 (resolveLink):
      - 위키 링크 구문 내부의 텍스트가 순수 목차 번호(1.2.3), 단순 제목(개요), 혹은 번호와 제목의 복합형(1.2. 개요)인지
        등 모든 형식을 정규식으로 유연하게 해체하여 해당되는 실제 대상의 문서 UUID를 찾아냅니다.
  - 더블 클릭 라우팅 내비게이션:
      - 사용자가 작성한 본문 텍스트 내에서 [[ ... ]] 링크 안을 더블 클릭하는 동작을 취할 경우, 해당 텍스트 세그먼트를 분리
        판정하고 식별 엔진을 통과시켜 대상 문서로 화면을 즉각 전환(라우팅)해 줍니다.
  - 자동 명칭 변경 리팩토링 시스템 (globalBatchSyncWikiLinks):
      - 기획서 내에서 어떤 문서의 제목이 바뀌거나 계층 위치 변경으로 목차 번호가 바뀌는 상황이 발생하면, 프로젝트 내 모든 문서의
        본문을 백그라운드에서 추적 검사합니다.
      - 그 후 옛날 양식의 위키 링크 구문(예: [[1. 옛제목]])을 새로 바뀐 포맷인 [[2. 새제목]]으로 일괄 검색 변환하여,
        작성된 문서 내 모든 위키 링크들의 연결 구조가 항상 끊어지지 않도록 최신 상태로 조율합니다.
  - 문맥 분석 기반 역링크 창 (Alt + B):
      - 현재 문서를 참조하고 언급한 다른 모든 문서를 수집하는 시스템입니다.
      - 단순 목록 나열에 그치지 않고, 가리키는 링크 주변 35바이트 앞뒤의 문자열 맥락을 고스란히 발췌하여 요약 문장으로 엮어 줍니다.
      - 요약 목록에서 타겟 문서를 클릭하면 즉시 해당 위치로 페이지가 슬라이딩 전환됩니다.

6. 기타 부가 인터랙티브 기능 (Utils)

작업 능률 향상을 목표로 배치된 정밀 편의 도구 세트입니다.

  - 축소형 인터랙티브 브레드크럼 바:
      - 현재 작업 중인 문서의 상위 경로들을 보여 주되, 경로 깊이가 3단계를 초과하면 이전 경로들을 ...으로 영리하게 합산해 시야를
        좁힙니다.
      - 또한 다른 페이지에서 위키 링크 더블 클릭 등을 타고 넘어왔을 때, 이전으로 돌아갈 수 있는 디딤돌 장치인 "↩ [문서명]에서
        건너옴" 히스토리 링크를 차분한 무채색 디자인으로 띄워 줍니다.
  - 동일 위상 빠른 마우스 휠 네비게이션 (Ctrl + Wheel):
      - Ctrl 키를 누른 상태에서 마우스 휠을 돌리면 트리 리스트에 정렬된 정규 문서들의 배치 순서에 입각하여 이전/다음 문서로 즉시
        이동할 수 있어 마우스 이동을 최소화합니다.
  - 단축키 링크 삽입 (Ctrl + L):
      - 에디터에서 위키 링크를 수동 기입할 필요 없이, Ctrl+L 입력 시 열리는 팝업에서 화살표 키나 키워드 입력으로 원하는 문서를
        빠르게 찾아 본문에 바로 위키 주소를 매핑 주입해 줍니다.
  - 맞춤법 검사(Spellcheck) 활성/비활성 제어:
      - 기획서 내 붉은 밑줄의 노출 여부를 토글하여 문서 가독성 모드를 원클릭으로 선택할 수 있습니다.
  - 정리된 클립보드 내보내기 ("문서 복사" 기능):
      - 현재 문서의 정확한 계층 경로 구조(프로젝트명>>1.부모>>1.1.자식)와 제목 및 본문을 정해진 무수식 규격으로 깔끔하게
        정돈하여 시스템 클립보드에 담아 줍니다.
